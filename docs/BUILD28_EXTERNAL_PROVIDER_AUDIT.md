## Security and product rules

- No secret belongs in the iOS app, repository, test fixture, diagnostic event or result renderer.
- Provider responses must retain source URL/provider, retrieval time and partial/unavailable state.
- Missing external data never changes local/system/personal router priority and never fabricates current facts, prices, availability or completion.
- The current exact owner boundary for general/current information is one Brave Search account/plan/API key; independent source repair continues while that action is pending.
