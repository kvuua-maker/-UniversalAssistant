# M9 Sponsored and Organic Separation Core

The existing deterministic `OfferRanker` remains the sole organic ordering path and receives no commission or campaign value. All lawful verified offers remain in organic eligibility, including useful non-partner results and offers that also have a campaign.

Sponsored placements are produced as a separate collection only for enabled, in-period, funded campaigns with an explicit locale disclosure. A missing disclosure suppresses the sponsored placement rather than allowing it to masquerade as organic. Campaign budget is configuration data and never changes factual offer values or organic order.
