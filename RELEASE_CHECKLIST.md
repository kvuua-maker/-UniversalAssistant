# Release Checklist

- [x] Development/Staging/Production build configurations exist
- [x] Secrets and generated files ignored
- [x] Simulator SDK build succeeds
- [x] Required permission usage strings reflect implemented capabilities; current privacy manifest and Required Reason API audit pass
- [x] Five-language localization and accessibility automated QA
- [x] CI runs static checks, backend tests and a real iOS simulator test build
- [x] Release artifacts carry commit and toolchain identity
- [x] Runtime feature configuration supports tested rollback to a known version
- [ ] Real-device matrix completed
- [ ] Signing, TestFlight and App Store owner actions
- [ ] Owner/legal-approved public privacy/support URLs and App Store metadata (local drafts/inventory complete; live queue)
- [ ] Commerce affiliate disclosure, provider terms and current Apple commerce rules verified
- [ ] No “lowest/best/bought/commission” claim without required real evidence
